# ☕ Coffee Sales Analysis Dashboard | Power BI

## 📖 Overview
An interactive Coffee Sales Dashboard built using **Power BI** to analyze sales performance, monitor KPIs, and generate actionable business insights. The project demonstrates data cleaning, data modeling, DAX calculations, and interactive dashboard design.

## 🚀 Features
- Total Revenue Analysis
- Total Orders Tracking
- Average Order Value (AOV)
- Monthly Sales Trend
- Top 5 Best-Selling Coffee Products
- Sales by Time of Day
- Interactive Filters
- Detailed Data Table

## 🛠️ Tools & Technologies
- Microsoft Excel (Basic Data Cleaning)
- Microsoft Power BI
- Power Query
- DAX

## 📊 Key KPIs
- Total Revenue
- Total Orders
- Average Order Value
- Best Selling Coffee
- Best Selling Day

## 💡 Business Recommendations
- Maintain inventory for high-demand products.
- Increase staff during peak sales periods.
- Promote low-selling products with special offers.
- Use sales trends for better planning.
- Monitor KPIs for data-driven decisions.
